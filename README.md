## ✨ Key Features

- **Responsive Architecture:** Thoughtfully engineered for both mobile and desktop viewports with zero layout breakage or horizontal overflow.
- **Project Gallery Component:** Dynamic project showcase with real-time category filtering (*All*, *Full-Stack*, *Agentic AI*, *Tools*), detailed tech stack breakdowns, live demo links, and GitHub repository access.
- **Interactive Chess Arena (`/play`):** Fully playable interactive chess game against an AI chess engine (Stockfish.js & Chess.js) featuring an in-game conversational companion.
- **Projects Archive (`/myworks`):** Comprehensive archive of projects with categorized cards and quick action links.
- **High-Contrast Dark Theme:** Elegant dark palette (`#09090b` canvas with `#18181b` surface cards) with typography pairing **Playfair Display** (headings) and **Plus Jakarta Sans** (body & UI).
- **Working Contact Form:** Interactive contact mechanism with form state handling and one-click email copying.

## 🚀 Getting Started

### 1) Clone the Repository

```bash
git clone https://github.com/alfa546/Nouman-sajid-portfolio.git
cd Nouman-sajid-portfolio
```

### 2) Install Dependencies

```bash
npm install
```

### 3) Start the Local Development Server

```bash
npm run dev
```

The app will be available at `http://localhost:3000`.

### 4) Build for Production

```bash
npm run build
```
