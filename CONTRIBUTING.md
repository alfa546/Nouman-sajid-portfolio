# Contributing to Nouman Sajid's Portfolio

First off, thank you for considering contributing to this project! It's people like you that make the developer community such a great place to learn and collaborate.

## 📝 Code of Conduct

By participating in this project, you are expected to uphold a respectful and considerate environment. Please be kind and constructive when submitting issues or pull requests.

## 🛠️ How Can I Contribute?

### Reporting Bugs
If you find a bug in the project, please open an issue in the repository. Make sure to include:
- A clear and descriptive title.
- Steps to reproduce the bug.
- Expected behavior vs. actual behavior.
- Browser and device information.
- Screenshots or screen recordings if applicable.

### Suggesting Enhancements
We are always looking for ways to improve the portfolio! If you have an idea for a new feature, 3D effect, or UI enhancement, feel free to open an issue or start a discussion. Provide as much context as possible.

### Submitting Pull Requests
1. **Fork the repository** to your own GitHub account.
2. **Clone the project** to your local machine:
   ```bash
   git clone https://github.com/alfa546/Nouman-sajid-portfolio.git
   cd Nouman-sajid-portfolio
   ```
3. **Create a new branch** for your feature or bug fix:
   ```bash
   git checkout -b feature/your-feature-name
   ```
   *(Use prefixes like `feature/`, `bugfix/`, or `docs/` for clarity.)*
4. **Install dependencies**:
   ```bash
   npm install
   ```
5. **Make your changes** and test them locally. You can start the development server with:
   ```bash
   npm run dev
   ```
6. **Ensure code quality**:
   Run the linter to make sure your code follows the project's style guidelines before committing:
   ```bash
   npm run lint
   ```
   If there are type checking issues, you can verify with:
   ```bash
   npm run build
   ```
7. **Commit your changes** with clear and descriptive commit messages.
8. **Push to your fork**:
   ```bash
   git push origin feature/your-feature-name
   ```
9. **Submit a Pull Request** to the `main` branch of this repository. Provide a detailed description of your changes in the PR.

## 🧑‍💻 Development Setup & Tech Stack

This project is built with a modern web stack:
- **Frontend:** React, TypeScript, Vite
- **3D & Animations:** Three.js, React Three Fiber, GSAP
- **Styling:** CSS3, Tailwind CSS (if applicable)

When making changes, especially to the 3D rendering components (typically under `src/components/`), please ensure performance remains smooth across both desktop and mobile views.
